# explainable-multiomics-syndrome-prediction
An explainable multi-omics AI framework for diagnosing genetic syndromes (Down, DiGeorge, Klinefelter, Turner). It combines ComBat batch harmonization, L1 sparse biomarker selection, and SVM classification with SHAP game theory for auditable patient decisions, powered by an interactive real-time dosage simulation dashboard achieving 97.4% ROC-AUC.
