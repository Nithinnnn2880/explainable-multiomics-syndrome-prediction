    Mathematical & Algorithmic Formulation

    The formal mathematical models underpinning our multi-omics pipeline: Empirical Bayes location-scale parameters, L1 feature sparsity, Support Vector Hilbert space projections, and cooperative Shapley force vectors.

    1. ComBat Empirical Bayes Location/Scale

    Stage 03

    Standardises expression tensors across heterogeneous microarray platforms using parametric empirical Bayes priors:

    $$Y_{ijg} = \alpha_g + X_j \beta_g + \gamma_{ig} + \delta_{ig} \epsilon_{ijg}$$

    Where $\alpha_g$ is baseline expression, $X_j \beta_g$ preserves syndrome status, and $\gamma_{ig}, \delta_{ig}$ isolate technical batch shifts.

    2. L1 Sparse Feature Selection

    Stage 04

    Constrains feature space from 20,441 genes to 24 critical biomarkers using coordinate-wise convex regularisation:

    $$\min_{\mathbf{w}} \left\{ \frac{1}{2n} \|\mathbf{y} - X\mathbf{w}\|_2^2 + \lambda \|\mathbf{w}\|_1 \right\}$$

    At $\lambda = 0.08$, non-informative genomic noise coefficients are set identically to zero, isolating the chromosomal lesion drivers.

    3. Dual-Kernel SVM Specialist

    Stage 05

    Aggregates Linear and Radial Basis Function (RBF) specialist classifiers into calibrated posterior probabilities:

    $$f(\mathbf{x}) = \text{sign}\left( \sum_{i \in \text{SV}} \alpha_i y_i K(\mathbf{x}_i, \mathbf{x}) + b \right)$$ $$K_{\text{RBF}}(\mathbf{x}_i, \mathbf{x}_j) = \exp\left( -\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2 \right)$$

    Specialist models achieve orthogonal hyperplane separation, yielding an uncalibrated margin distance directly reflecting cytogenetic dosage.

    4. Shapley Additive Explanations

    Stage 06

    Decomposes multi-omics patient vectors into exact axiomatic force attributions using cooperative game theory:

    $$\phi_i(v) = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!(|N| - |S| - 1)!}{|N|!} \left[ v(S \cup \{i\}) - v(S) \right]$$

    Satisfies efficiency $\sum_i \phi_i = f(x) - \mathbb{E}[f(x)]$, ensuring all positive and negative shifts are mathematically accounted for.
